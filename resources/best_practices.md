# Anti-Phishing Best Practices

## 1. Verify Emails

Do:

- Verify the sender's address and complete domain
- Hover over links before clicking
- Check attachments before opening them
- Review spelling, grammar, and context

Avoid:

- Clicking suspicious links
- Replying with sensitive information
- Opening unsolicited attachments

## 2. Protect Your Accounts

- Use long, unique passwords
- Never reuse the same password
- Enable two-factor authentication
- Use a trusted password manager

## 3. Report Attacks

When you receive a suspected phishing attempt:

1. Do not interact with the message
2. Capture a screenshot if useful for investigation
3. Delete the message after reporting it
4. Report it to your IT or security team
5. Notify the impersonated organization when appropriate

## 4. Keep Learning

- Run regular security awareness sessions
- Use controlled phishing simulations responsibly
- Share information about new phishing techniques
- Build a culture of security reporting

## 5. Incident Response

If you entered information or clicked a malicious link:

1. Change affected passwords immediately
2. Contact your bank if financial information was exposed
3. Report the incident to your IT or security team
4. Keep a record of what happened and when
5. Review and update your account recovery options
